Open Xiao maintenance fixes
Date: 2026-08-14
Built source tree: maintenance series rebased onto release commit bb4879e

Runtime and security fixes
- Fresh-read authorization is scoped by stream, so one agent cannot authorize
  another agent's file mutation.
- Chat IPC rejects excessive aggregate message, text, part, and image payloads.
- Provider error bodies stop on cancellation or a five-second idle deadline.
- OpenCode event streams fail after ten minutes without event bytes, releasing
  the per-thread stream lock.
- OpenCode approval bindings are cleared at stream ownership boundaries.
- Removing a workspace revokes and terminates its active terminal sessions.
- Unknown permission and agent mode strings are rejected at the Rust IPC boundary.
- Project file search failures settle loading and show an explicit error.
- Review Undo availability clears immediately on thread changes and stays disabled
  when snapshot lookup fails.

Maintenance and verification improvements
- Added Vitest, jsdom, and Testing Library to the existing frontend test gate.
- Added behavioral tests for project file search failure, Review Undo ownership,
  and Auth modal Escape/focus behavior.
- Extracted Review Undo availability from App.tsx and lazy-loaded the project file
  picker to keep the production entry chunk below 500 kB.
- Added standalone website lint, typecheck, and production build checks to CI.
